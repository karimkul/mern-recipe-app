# Food Recipe App

This is a simple web application that allows users to view and share food recipes. The application fetches recipe data from a backend server and displays it dynamically in the frontend.

## Features

-   Display a list of recipes fetched from a backend API.
-   Show details for each recipe, including name, description, and image.
-   User-friendly UI with easy navigation.
-   Backend and frontend are connected using Axios.

## Technologies Used

-   **Frontend**: React.js
-   **Backend**: Node.js, Express.js (assuming this is the backend used)
-   **Styling**: CSS (or Tailwind CSS if you're using it)
-   **State Management**: React Hooks (`useState`, `useEffect`)
-   **API Requests**: Axios
